# 预备篇自测

## 题目

1. 程序和进程有什么区别？同一进程的线程通常共享什么？
2. `fork()` 后子进程修改局部变量，为什么父进程的对应变量不随之改变？
3. 普通函数调用和系统调用分别在哪里执行？
4. 一个外部内核模块的加载函数和卸载函数分别在什么时候运行？
5. 为什么安装普通用户态头文件不能代替运行内核对应的构建目录？
6. 模块编译成功后，还需要什么实验才能说明当前系统可以运行它？

## 参考答案

1. 程序是可执行代码及数据；进程是运行中的程序及其资源。线程通常共享所在进程的地址空间和打开文件等资源。
2. 父子进程有各自的虚拟地址空间；即使地址数值相同，修改也不会直接改变对方的私有数据。
3. 普通函数在调用进程的用户态执行；系统调用通过内核入口执行相应内核代码，返回后继续用户态。
4. 加载时运行初始化函数；模块成功卸载时运行退出函数。
5. 外部模块需要匹配目标内核的 kbuild、配置、生成头文件及可能需要的符号版本信息，用户态头文件不包含完整构建环境。
6. 在目标内核加载模块、检查日志并成功卸载；具体还受权限、签名策略和内核配置影响。
